# Gesture Control Computer Vision

A real-time hand tracking and gesture recognition project using Python, OpenCV, and MediaPipe.

## Current Features

- Real-time webcam hand tracking
- Hand landmark detection
- One-finger detection
- Two-finger detection
- Open-palm detection
- Fist detection

## Technologies Used

- Python
- OpenCV
- MediaPipe

## Project Status

🚧 Currently under development.
